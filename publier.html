Réglages

Discord

  1. Dans Discord : clic droit sur le salon → Modifier le salon
  2. Intégrations → Webhooks → Nouveau webhook
  3. Copier l'URL du webhook, puis la coller ci-dessus

Site des BD (GitHub)

Sous la forme pseudo/nom-du-dépôt. Rempli automatiquement quand cette page est ouverte depuis le site.

  1. Sur GitHub : photo de profil → Settings → Developer settings
  2. Personal access tokens → Fine-grained tokens → Generate new token
  3. Repository access : « Only select repositories », choisir le dépôt du site
  4. Permissions → Repository → Contents : Read and write
  5. Générer, copier la clé et la coller ci-dessus

Le webhook et la clé restent enregistrés sur cet appareil uniquement. Ne les partage pas : ils permettent de publier.
